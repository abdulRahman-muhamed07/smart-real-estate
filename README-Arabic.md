## 🚀 مميزات المنصة

### 👥 مميزات للمستخدمين العاديين

| الميزة | الوصف |
|--------|-------|
| 🔍 **بحث متقدم** | البحث عن العقارات مع تصفية حسب المدينة، السعر، المساحة، نوع العقار |
| 🏘️ **تصفح العقارات** | عرض جميع العقارات مع إمكانية الفلترة حسب نوع المعاملة (بيع/إيجار) |
| 📄 **تفاصيل العقار** | عرض كامل معلومات العقار مع الصور والوصف وموقع العقار |
| ❤️ **المفضلة** | حفظ العقارات المفضلة في قائمة شخصية للعودة إليها لاحقاً |
| 🛒 **الحجز** | حجز العقارات المهتم بها والاتصال بالبائع |
| ⭐ **التقييمات** | إضافة تقييمات ونجوم وتعليقات على العقارات |
| 📊 **لوحة التحكم** | متابعة الحجوزات والمفضلة وإدارة الحساب |

### 🏢 مميزات للبائعين (المطورين العقاريين)

| الميزة | الوصف |
|--------|-------|
| 📝 **إضافة عقار** | نشر عقار جديد مع صور ووصف تفصيلي والسعر |
| ✏️ **تعديل العقار** | تحديث بيانات العقار في أي وقت |
| 🗑️ **حذف العقار** | حذف العقار من المنصة |
| 📅 **إدارة الحجوزات** | استلام طلبات الحجز وتأكيدها أو رفضها |
| 📊 **لوحة بائع** | إحصائيات عن عقاراته وحجوزاته |

### 🛡️ مميزات للمديرين (الأدمن)

| الميزة | الوصف |
|--------|-------|
| 📊 **لوحة الإحصائيات** | إحصائيات كاملة عن المنصة (المستخدمين، العقارات، الحجوزات) |
| 👥 **إدارة المستخدمين** | عرض جميع المستخدمين وحذف أي مستخدم |
| 🏘️ **إدارة العقارات** | عرض جميع العقارات وتعديلها أو حذفها |
| 📈 **متابعة المنصة** | مراقبة نشاط المنصة بشكل مستمر |

## 👥 الادوار والصلاحيات

### 👤 الدور الأول: المستخدم (User)

- تصفح العقارات والبحث فيها
- عرض تفاصيل أي عقار
- إضافة العقارات للمفضلة
- حجز العقارات
- إضافة تقييمات وتعليقات
- متابعة الحجوزات والمفضلة في لوحة التحكم

### 🏢 الدور الثاني: البائع (Vendor)

- **جميع صلاحيات المستخدم**
- إضافة عقارات جديدة مع صور
- تعديل وحذف عقاراته الخاصة
- استلام طلبات الحجز على عقاراته
- تأكيد أو رفض طلبات الحجز
- لوحة تحكم خاصة للبائعين

### 🛡️ الدور الثالث: المدير (Admin)

- **جميع صلاحيات البائع والمستخدم**
- لوحة إحصائيات شاملة للمنصة
- عرض جميع المستخدمين
- حذف أي مستخدم
- عرض جميع العقارات
- تعديل أو حذف أي عقار
- إدارة كاملة للمنصة

## 🖥️ الصفحات الرئيسية

### 1. الصفحة الرئيسية (index.html)
- banner رئيسي مع عنوان المنصة
- خدمات للمنصة (شراء - بيع - إيجار)
- إحصائيات عدد العقارات والمستخدمين
- آراء العملاء
- روابط التواصل الاجتماعي

### 2. صفحة العقارات (all-properties.html)
- عرض جميع العقارات
- فلترة حسب نوع المعاملة (بيع/إيجار)
- ترتيب حسب السعر أو التاريخ
- صفحات متعددة للعقارات

### 3. صفحة تفاصيل العقار (details.html)
- صور العقار
- السعر والموقع
- عدد الغرف والحمامات والمساحة
- وصف العقار
- زر حجز العقار
- زر إضافة للمفضلة
- قسم التقييمات والتعليقات

### 4. صفحة البيع (sell.html)
- نموذج إضافة عقار جديد
- إدخال: العنوان، السعر، المدينة، المساحة، الغرف، الحمامات
- رفع الصور (حتى 8 صور)
- اختيار نوع المعاملة (بيع/إيجار)
- وصف العقار

### 5. صفحة تسجيل الدخول (login.html)
- إدخال البريد الإلكتروني وكلمة المرور
- تسجيل الدخول عبر JWT
- تخزين رمز الأمان في المتصفح

### 6. صفحة التسجيل (signup.html)
- إدخال: الاسم، البريد، الهاتف، كلمة المرور
- اختيار الدور (مستخدم/بائع)

### 7. صفحة لوحة التحكم (dashboard.html)
- تبويب عقاراتي (للأوبار فقط)
- تبويب طلباتي (الحجوزات)
- تبويب المحفوظة (المفضلة)
- تبويب الحساب (إعدادات)

### 8. صفحة الأدمن (admin.html)
- إحصائيات المنصة
- إدارة المستخدمين (عرض + حذف)
- إدارة العقارات (عرض + تعديل + حذف)

### 9. صفحة المفضلة (wishlist.html)
- عرض العقارات المحفوظة
- إزالة من المفضلة

## 💡 الخدمات المقدمة

### 🔐 نظام الأمان والتوثيق
- تسجيل الدخول والتسجيل
- رمز JWT للتوثيق
- تشفير كلمات المرور
- حماية الروابط حسب الدور

### 📸 رفع الصور
- دعم حتى 8 صور لكل عقار
- رفع على Cloudinary (سحابة)
- صور بديلة جاهزة في حال عدم التوفر

### 🔎 محرك البحث
- بحث بالنص
- فلترة حسب المدينة
- فلترة حسب السعر
- فلترة حسب المساحة
- ترتيب نتائج البحث

### 📅 نظام الحجز
- إرسال طلب حجز
- تأكيد أو رفض البائع
- إلغاء الحجز من المستخدم
- تحديث حالة العقار تلقائياً

### ⭐ نظام التقييم
- تقييم من 1 إلى 5 نجوم
- إضافة تعليق
- يمكن للمستخدم تقييم عقار واحد فقط

### ❤️ نظام المفضلة
- إضافة العقار للمفضلة
- عرض قائمة المفضلة
- إزالة من المفضلة
- مزامنة مع قاعدة البيانات

## 🚀 تشغيل المشروع

### الطريقة الأولى: تشغيل سريع (موصى بها)

```
Double-click على ملف: run-project.bat
```

سيبدأ تلقائياً:
1. تشغيل الخادم الخلفي على بورت 5001
2. تشغيل الخادم الأمامي على بورت 8000
3. فتح المتصفح تلقائياً

### الطريقة الثانية: تشغيل يدوي

#### الخطوة 1: تشغيل الخادم الخلفي
```bash
cd smart-real-estate-backend
npm install
node server.js
```

#### الخطوة 2: تشغيل الخادم الأمامي
```bash
node dev-server.js
```

#### الخطوة 3: فتح الموقع
```
http://localhost:8000
```

## 📝 ملاحظات مهمة

1. **البريد الإلكتروني**: يجب أن يكون فريداً (لا يمكن استخدام بريد مسجل)
2. **حالة العقار**: عقار واحد لكل مستخدم (حجز واحد نشط)
3. **التقييم**: مرة واحدة فقط لكل مستخدم على كل عقار
4. **حذف الأدمن**: لا يمكن حذف آخر مدير في المنصة

## ❓ الأسئلة الشائعة

### كيف أضيف عقار؟
1. سجل دخولك كبائع
2. اذهب لصفحة "بيع"
3. املأ البيانات وارفع الصور
4. اضغط "نشر العقار"

### كيف أحجز عقار؟
1. اذهب لصفحة تفاصيل العقار
2. اضغط زر "حجز الآن"
3. ستصلك رسالة تأكيد

### كيف أصبح بائع؟
1. سجل حساب جديد
2. اختر دور "بائع" أثناء التسجيل
3. سيصلك توثيق بعد مراجعة الأدمن

### كيف أدخل لوحة الأدمن؟
1. سجل دخولك بـ admin@seed.com
2. اضغط على "الإدارة" في القائمة العلوية
