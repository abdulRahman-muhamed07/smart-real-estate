# العقار الذكي | Smart Real Estate

منصة عقارية متطورة تعتمد على الذكاء الاصطناعي لتقييم العقارات وتسهيل عمليات البيع والشراء في مصر.

## بنية المشروع (Project Structure)

تم تقسيم المشروع إلى عدة صفحات لضمان سهولة الإدارة والتطوير:

- **index.html**: الصفحة الرئيسية (Landing Page) التي تحتوي على عرض الخدمات والتقييم السريع.
- **home.html**: صفحة تصفح العقارات والبحث المتقدم.
- **login.html**: صفحة تسجيل الدخول.
- **signup.html**: صفحة إنشاء حساب جديد.
- **assets/**:
    - **css/**: ملفات التنسيق المنفصلة (Global, Auth, Home, Landing).
    - **js/**: الملفات البرمجية المشتركة (AI Logic, rendering).

## التكنولوجيات المستخدمة (Technologies Used)

- **HTML5 & Tailwind CSS**: لبناء الواجهات العصرية المتجاوبة.
- **JavaScript (ES6+)**: للتحكم في المنطق البرمجي وواجهات المستخدم.
- **Gemini AI API**: لتقديم تقييمات دقيقية للعقارات ومساعد ذكي (Chatbot).

## المميزات (Features)

1. **تقييم ذكي**: تحليل بيانات العقار وتوقع السعر العادل باستخدام AI.
2. **بحث PRO**: خوارزميات متقدمة لتصفية العقارات بناءً على احتياجات المستخدم.
3. **مساعد ذكي**: شات بوت متوفر في كل الصفحات للرد على استفسارات المستخدمين.
4. **تصميم عصري**: واجهة مستخدم توفر تجربة سلسة وفاخرة.
