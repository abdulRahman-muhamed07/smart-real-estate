# العقار الذكي | Smart Real Estate

منصة عقارية متطورة تعتمد على الذكاء الاصطناعي لتقييم العقارات وتسهيل عمليات البيع والشراء في مصر. تم تحديث التصميم بالكامل ليكون أكثر احترافية وعصرية بناءً على معايير Figma الحديثة.

## بنية المشروع (Project Structure)

تم تقسيم المشروع إلى عدة صفحات لضمان سهولة الإدارة والتطوير:

- **index.html**: الصفحة الرئيسية (Landing Page) - عرض الخدمات والتقييم السريع الذكي.
- **home.html**: صفحة البحث المتقدم - تصفح العقارات مع فلاتر ذكية وسحب (Range Filter).
- **login.html**: صفحة تسجيل الدخول بتصميم مودرن.
- **signup.html**: صفحة إنشاء حساب جديد.
- **sell.html**: صفحة عرض العقارات للبيع - نموذج بيانات متكامل.
- **details.html**: صفحة تفاصيل العقار - عرض الصور والبيانات الكاملة وطلب الشراء.
- **assets/**:
    - **css/**: ملفات التنسيق المنفصلة (Global, Auth, Home, Landing).
    - **js/**: المنطق البرمجي للذكاء الاصطناعي (Gemini API) وعرض البيانات.

## التكنولوجيات المستخدمة (Technologies Used)

- **HTML5 & Tailwind CSS**: واجهات عصرية متجاوبة بنظام ألوان Blue/Emerald.
- **JavaScript (ES6+)**: للتحكم في المنطق البرمجي وديناميكية الواجهات.
- **Gemini AI API**: لتقديم تقييمات دقيقية للعقارات ومساعد ذكي (Chatbot).

## المميزات الجديدة (New Features)

1. **تصميم احترافي**: نظام ألوان جديد (Blue/Green) يوفر تجربة مستخدم فاخرة.
2. **فلاتر ذكية**: شريط جانبي متطور لتصفية العقارات حسب النوع والسعر.
3. **تقييم ذكي**: تحليل بيانات العقار وتوقع السعر العادل باستخدام AI في الصفحة الرئيسية.
4. **صفحات متكاملة**: تم إضافة صفحات تفاصيل العقار ونماذج البيع لتجربة مستخدم شاملة.
